# Aaron Daniel S. Paderes — Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript. It uses a black, red, and white theme.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and automatic year
- `profile.jpg` — optional profile picture you add

## Add your picture
Upload your photo to the same repository folder as `index.html` and name it exactly `profile.jpg`. The website shows a placeholder until you upload it.

## Before publishing
- Replace `your.email@example.com` in `index.html` with your real email.
- Update the example project descriptions to match projects you have actually completed.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your repository's main folder.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.
5. Wait for GitHub Pages to publish. The URL usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

No installation is required.
